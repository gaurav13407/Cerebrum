CEREBRUM ON LICHESS — STARTUP

1. Build the engine if you have changed its source code:

   cd /Users/gaurav/Desktop/Cerebum
   make

2. Save the token once in lichess-bot's local configuration:

   cd /private/tmp/lichess-bot
   nano config.yml

   Replace the first line's placeholder with your bot API token, keeping it
   between the quotation marks, then save with Ctrl+O, Return, Ctrl+X.
   The file is excluded by lichess-bot's .gitignore. Restrict it to your user:

   chmod 600 config.yml

3. Start the Lichess bot bridge:
   cd /private/tmp/lichess-bot
   source venv/bin/activate
   unset LICHESS_BOT_TOKEN
   python3 lichess-bot.py -u

4. Leave that Terminal window open. The bot is ready when the log says it is
   connected and awaiting challenges. Challenge it from your personal account.

5. When you are finished, return to Terminal and press Ctrl+C to stop the bot.
